## What we have built - 

### HomeChef

An ingredient-first cooking community for Indian households. The prototype explores recipe discovery based on ingredients people already have, regional cooking ideas, and a place to share trusted home recipes.

**Stack:** React · Node.js · Express · MongoDB  
[Project overview](https://tech-lead.in/projects/19) 

### Udhari App

A peer-to-peer lending prototype for money shared between friends and family. It brings conversations, mutually approved loan terms, partial repayments, and a clear ledger into one place so both people can understand their agreement.

**Stack:** Flutter · Dart  
[Project overview](https://tech-lead.in/projects/25)

### Productivity Tracker

An in-progress app connecting tasks, time tracking, habits, and goals. It aims to help people see whether daily effort is moving meaningful outcomes and use that evidence to plan the next week.

**Stack:** React · Node.js · MongoDB · Chart.js  
[Project overview](https://tech-lead.in/projects/16)
